# 高中生活模拟器

一款以中国高中三年为背景的文字模拟游戏（网页）。玩家每周安排 16 个决策点，在课程、社交、恋爱与综评之间做取舍；AI 只负责把系统算出来的事实写成场景，不参与数值。

## 跑起来

**最简单的方式**：双击 `启动游戏.bat`。它会检查 Node、装依赖、启动服务器并打开浏览器。没装 Node 的话，脚本会打开下载页。

macOS 用 `启动游戏.command`，第一次需要 `chmod +x 启动游戏.command`。

**命令行**：

```bash
npm install
npm run dev      # http://127.0.0.1:5180
npm run server   # 可选：AI 代理，127.0.0.1:8787
```

不启动代理也能玩，事件走内置模板；在「设置」里填代理地址与模型，社交事件改由 AI 即时生成。

## 有什么

- **五学段**：高一上/下、高二上/下、高三，共 122 周，含寒暑假与假期规则
- **3+1+2 选科**：高一上九科全考，结束后填表，非选科目冻结并走合格考
- **考试**：简化 IRT + 临场系数，期中/期末/模考/高考，赋分按 A–E 比例换算
- **遗忘**：越熟掉得越快，学习会暂停衰减；难度决定系数
- **课堂 + 自主**：白天课程给固定学习量，自习收益含课堂量的百分比加成
- **知识星图**：187 个单元、175 条关联边（按九科关联目录重建）
- **社交**：12 名同学各有存档与性格，关系网由外向度驱动；朋友、暧昧、恋爱、分手
- **事件**：50+ 条，分主线/日常/社交/朋友/暧昧/恋爱六组
- **综评与结局**：五育结算、合格考、综评升学与高考结局

## 开发

纯前端 TypeScript + React，模拟核心在 `src/sim/`，不依赖 DOM，可直接在 Node 里跑：

```bash
node scripts/full-sim.mjs six normal   # 完整三年模拟
```
